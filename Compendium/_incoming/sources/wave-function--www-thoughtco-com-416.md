# Wave Function
- A wave function is defined as a function describing the probability of a particle's quantum state as a function of position, momentum, time, and/or spin.
- The wave function is commonly denoted by the variable Ψ (Psi).
- The wave function may include an imaginary number and is squared to yield a real number solution to assess the probability of finding an electron within a matter wave.
- The concept of the wave function was introduced by the famous Schrodinger equation in 1925.
