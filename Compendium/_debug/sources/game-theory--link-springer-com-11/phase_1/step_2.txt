- Living reference work entry

- Later version available View entry history

- First Online: 01 January 2014

- Cite this living reference work entry

- This article provides an overview of the aspects of game theory that are covered in this Encyclopedia, which includes a broad spectrum of topics on static and dynamic game theory.
- It starts with a brief overview of game theory, identifying its basic ingredients, and continues with a brief historical account of the development and evolution of the field.
- It concludes by providing pointers to other articles in the Encyclopedia on game theory, and a list of references.
